# Bravo Skills

> Coleção de ferramentas de IA para gestão de projetos de engenharia.
> Mantido por **Fabiano Thomé** / [**BravoCP**](https://www.bravocp.com.br) — Engenharia do Proprietário.

---

## O que é isto

Cada pasta deste repositório é uma **skill** — um pequeno produto autocontido que resolve um problema específico de gestão de projetos, distribuído como configuração de IA pronta para uso (Gemini Gem, Claude Code skill, prompt portátil) **mais** os artefatos de apoio (templates, exemplos, scripts).

A tese é simples: codificar conhecimento de engenharia de projetos em pacotes pequenos, gratuitos e compartilháveis, criando uma comunidade ao redor de práticas concretas.

## Para quem é

Cada skill aqui é desenhada para um perfil específico. Em geral:

- **Planejadores e engenheiros de obra** que precisam de respostas rápidas sem instalar nada na máquina.
- **Gestores de projeto** que querem ferramentas leves para apoiar reuniões e atualizações semanais.
- **Profissionais de engenharia** que valorizam método explícito e querem ver "como o cálculo é feito".

Cada skill tem seu próprio README com instruções de uso e exemplos.

---

## Como usar

A maioria das skills aqui pode ser usada de duas formas:

1. **Conversando com um Gemini Gem público** (grátis, requer apenas conta Google) — o caminho mais simples.
2. **Como skill do Claude Code** ou rodando os scripts Python localmente — para usuários mais técnicos.

Os links e instruções estão no README de cada skill.
