## A ideia

Em obras de capital com muitos contratados — silos, frigoríficos, esmagadoras, terminais portuários — o fator mais crítico de coordenação não é o cronograma de cada fornecedor. É a **interface entre contratados**: quando um precisa entrar, quando o anterior precisa ter saído, e quem fica bloqueado quando alguém atrasa.

A maioria das ferramentas pede que você consolide tudo em um único cronograma master. Isso é trabalhoso, frágil e quase nunca espelha a realidade. Esta skill propõe outro caminho:

- **Não consolide. Conecte.**
- Cada contratado é uma linha simples (entrada, saída, de quem depende).
- O algoritmo monta o grafo, calcula o caminho crítico e mostra onde está o bloqueio.
- Você atualiza semanalmente conforme a obra evolui.
